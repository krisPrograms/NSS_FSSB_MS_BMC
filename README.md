# NSS_FSSB_MS_BMC
The repository contains the files in Python and Z3 SMT solver for Bounded Model Checking for Coarse-Finer Models.
Citation : Ghosh, K. and Ball, J., 2026, January. Bounded Model Checking for Calibration of Systems Biology Models Under Uncertainty. In International Conference on Applied Algorithms (pp. 62-73). Cham: Springer Nature Switzerland.
